직무 요약

지난 5년간 국가 방위산업 및 글로벌 완성차 대기업의 엔터프라이즈 시스템을 주도하며, 대규모 트래픽 환경에서의 고가용성 아키텍처 설계와 데이터 보안 거버넌스 구축에 집중해 왔습니다.

특히 사용자 소속 및 역할에 따른 멀티테넌트(Multi-tenant) 완벽 데이터 격리, 전사 SSO 기반 2-Layer 인가(Authorization) 제어, 그리고 패킷 위변조를 방어하는 Zero Trust 기반 API 보안에 특화되어 있습니다.

단순한 기능 구현을 넘어, 관리자 화면에서 즉시 통제 가능한 코드리스(Code-less) 동적 권한 체계를 구축하고 쿼리 튜닝으로 대용량 데이터 처리 속도를 80% 이상 개선하는 등, B2B 엔터프라이즈 플랫폼이 요구하는 수준 높은 신뢰성과 확장성을 추구해 왔습니다.
